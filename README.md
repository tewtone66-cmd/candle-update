# Candle Update

Public update repository for Candle Client.

This repository contains **release assets only**.

- No Candle Client source code
- No private configuration
- No GitHub tokens
- No development project files

Published releases contain the downloadable Candle Client JARs used by the in-client updater.

## Release format

Use GitHub Releases with semantic version tags:

- `v1.6.1`
- `v1.6.2`
- `v1.6.3`

For Minecraft 1.21.11, the release JAR should contain `1.21.11` in its filename, for example:

`candle-1.21.11-1.6.1.jar`

The private source repository remains separate.
